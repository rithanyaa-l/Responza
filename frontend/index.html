Help & user guide

How to log the daily scrum, read the dashboard and export your data.

Getting started

  1. Open Mark attendance and pick the date (today is selected by default).
  2. Tap a status for every member of your module (the statuses are listed under Status key).
  3. Press Submit on your module heading. The module is locked until you press Edit.
  4. Open the Dashboard to see trends, the calendar and the monthly register.

Status key

Dashboard

  • Toolbar: search by name or module, filter by module and role, change month, jump to a date, add members, manage modules and roles, and export.
  • Overview cards: team size, who attended on the selected day, working days logged and average attendance for the month.
  • Monthly trend / Member summary: daily chart for the month, or one row per member with counts and an attendance bar. Use the i button on any section for a short explanation.
  • Yearly overview: one bar per month. Click a month to switch the dashboard to it.
  • Calendar view: attendance per day, colour-coded. Click a date to open it in Mark attendance.
  • Attendance register: read-only monthly grid grouped by module. Sort, filter, or click the column headings. Click a module heading to expand or collapse it.
  • Use Collapse all to fold sections away, and the section bar to jump between them.

Mark attendance

  • Selected date: use Prev day, Next day, Today or the calendar. Non-working days and holidays are not tracked.
  • Scrum taken by: defaults to the lead named in Settings. If they are absent, assign a team member for that date.
  • Marking: tap a status to set it and tap it again to clear it. The Mark all button fills everyone who is not locked with the default status from Settings.
  • Submit per module: every module has its own Submit button, enabled once all its members are marked. Edit unlocks it again.
  • Submit all modules (in the summary card) submits every pending module at once, and Unlock all reverses it.
  • A member who belongs to several modules has one record per day, so they are locked as soon as any of their modules is submitted.

Members, modules and roles

  • + Add member is available on both pages. Give a name, one role and one or more modules.
  • + Modules and + Roles add or remove modules and roles. Removing one never deletes attendance records.
  • Map members sets roles and modules for many people at once. Tick members, then use the bulk bar.
  • On Mark attendance, the ✕ beside a member removes them and all their records, after a confirmation.

Export

  • Export Excel gives a Summary sheet, one sheet per module, and an All Data sheet with filter arrows. Choose Month, Single day or All data, and which modules to include.
  • The All data option puts everything for a module on its own sheet: totals, every day, and a month-wise summary.
  • Export CSV saves the register you are looking at, so the current search, filter and sort apply.

Settings

  • ⚙ Settings holds everything the tracker uses: app and organization name, logo, the default scrum lead, statuses (code, label, colour, whether it counts as attended), the default status, working days and holidays.
  • Settings are stored in the shared database. When anyone saves them, every open page updates straight away.
  • Removing a status never deletes attendance: marks with that code are hidden until a status with the same code is added back.

Tips & shortcuts

  • / focus the search box   T switch light or dark theme   ← → previous or next month on the dashboard   Esc close a popup.
  • The page behind a popup stays still while it is open.

Your data

  • Everything is saved automatically to the shared MongoDB database. Everyone using the tracker sees the same records, and changes appear for everyone within moments.
  • The status at the top shows whether your latest change has been saved. Export to Excel any time you want an offline copy.
